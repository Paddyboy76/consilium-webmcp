# Hackathon requirements matrix

Verified September 2, 2026 against the [official challenge page](https://webmcp.devpost.com/), [official rules](https://webmcp.devpost.com/rules), and [official WebMCP resources](https://webmcp.devpost.com/resources). Deadline: **September 3, 2026 at 1:00 PM PDT**.

| Requirement / criterion | Current evidence |
|---|---|
| Working live URL | Public isolated Cloudflare Worker; health, UI, and bounded live journey passed |
| Public code + detectable license | Public GitHub repository on `main`; MIT detected by GitHub |
| Text description | Devpost-ready copy in `SUBMISSION.md` covers fit, UX, collaboration, and implementation |
| Demo video under three minutes | Exact honest recording script in `DEMO.md`; recording/upload remains user-dependent |
| WebMCP leverage | Seven stable typed tools plus state-dependent one-use commit tool; shared visible state and trace |
| Execution | Canonical D1, Workers AI/Vectorize retrieval, deterministic council, citations, abstention, and safe mutation lifecycle |
| Potential impact | Longitudinal memory preserves outcomes, failures, adaptations, causal links, confidence, and provenance across transient agent sessions |
| Creativity / ambition | An external browser agent collaborates with a user-appointed evidence council while capability availability encodes human approval state |

The official rules require a WebMCP-powered app, live URL, public licensed repository, specified text description, and a public YouTube demo with audio under three minutes. They do **not** require OpenAI Agents SDK, Responses API, or a GPT model. Those technologies are therefore not represented as live requirements or live evidence.

Current API usage is `document.modelContext.registerTool(tool, { signal })`; aborting the signal removes the dynamic commit tool. Read-only hints are applied to the six stable read tools. Trust boundaries are stated in tool descriptions and response payloads rather than invented metadata.

## Mandatory gap

- Record and publicly upload the under-three-minute YouTube demo, paste its URL into Devpost, complete the final signed-in review, and submit before the deadline.

## Optional, not submission-blocking

- Browser-prove the full proposal/commit/replay/reset lifecycle. It is already server-live proven; the current browser proof covers retrieval, council consultation, canonical grounding, visible trace, and guardrails.
- Activate the inactive OpenAI adapter only after separate paid-credential authorization and fresh end-to-end evidence.
